# 盘匣（PanXia）

一个直连自己 [OpenList](https://github.com/OpenListTeam/OpenList) 服务的安卓客户端。
**零第三方依赖**（纯 Android Framework + Java，连 AppCompat 都没有），APK 约 370 KB。

支持同时保存**多台服务器**随时切换；账号密码只存在本机。

> **作者**：zhj　|　**版本**：1.2　|　**许可证**：MIT　|　**服务端**：OpenList v4 API（在 v4.2.7 上验证）

盘匣是一个独立的第三方客户端，与 OpenList 官方及其任何官方移动端都不是同一个项目。

| 本地文件 | 设备存储目录浏览、名称 / 大小 / 类型 / 修改时间、递归搜索与排序、批量选择、新建、重命名、复制、移动、回收站恢复、上传到网盘 |
| 稳定性 | 惯性滑动不误开文件、多选跨目录不留脏数据、加载异常可重试、上传下载失败或取消自动清理半成品 |

## 多服务器

- 登录页顶部列出已保存的服务器，点一下即切换，也可以「＋ 添加新服务器」。
- 主界面右上角 **⋮ → 切换服务器** 进入服务器列表：切换 / 重命名 / 测试连接 / 删除。
- 设置页「当前服务器」右侧的 **切换 / 管理** 是同一个入口。
- 每台服务器的登录态、密码、上次停留的目录都是独立的；切回来还是原来的位置，不用重新登录。
- 地址相同的服务器不会重复添加，再次登录会覆盖更新那一条记录。

## 视频播放

点视频文件直接进入播放器，同一目录里的其他视频会自动排成播放列表。

| 操作 | 效果 |
| --- | --- |
| 单击画面 | 呼出 / 收起控制栏（播放中 4 秒自动隐藏） |
| 双击左半边 | 后退 10 秒，连双击递进到 30 / 60 / 120 秒 |
| 双击右半边 | 前进 10 秒，同上 |
| 双击中间 | 播放 / 暂停 |
| 拖动进度条 | 拖到哪放到哪，松手生效 |
| 右上角「横屏 / 竖屏」 | 手动切换方向（不跟随重力感应，避免躺着看时乱翻） |
| 右下角胶囊 | 倍速 0.75× ~ 2×、画面适应 / 拉伸 / 裁剪 |
| 右上角下载图标 | 保存到 `下载/PanXia/`，用其他播放器打开 |

退出时会记住播放位置，下次进来超过 15 秒会提示从上次位置继续；播完自动播放下一个。
倍速与上次一致，跨视频、跨次启动都保留。

## 音乐与歌词

进入音频文件后，**当前目录里的所有音频就是播放列表**，一曲结束自动下一首。

- 循环模式四种：顺序播放、列表循环（默认）、单曲循环、随机播放，按左下角胶囊切换，选择会记住。
- 封面是渐变底色 + 曲名首字母，颜色按文件名散列，不同歌不一样。
- 歌词取用顺序：
  1. 音频所在目录里的同名 `.lrc`（自己放的最准）；
  2. 本地缓存（上次取到过的）；
  3. 在线歌词库 [LRCLIB](https://lrclib.net)（免费、无需密钥），先精确匹配再模糊搜索。
- 拿到后缓存到应用私有目录，键是「目录 + 文件名 + 文件大小」，换了文件自动失效；
  确认没有歌词的会记住「没有」，下次不重复联网。
- 播放中锁屏或切到别的应用会继续放，退出这一页才停止（没有做常驻通知栏的后台服务）。

## 本地文件管理

主界面底栏「本地」进入，和网盘页完全分开；本地页使用独立的偏好设置，账号、登录态、断点、歌词缓存都不受影响。

| 能力 | 说明 |
| --- | --- |
| 浏览 | 目录浏览、面包屑返回，显示名称、大小、类型和修改时间 |
| 查找 | 当前目录及子目录递归搜索；按名称 / 大小 / 时间排序（可倒序） |
| 批量 | 长按进入多选，全选、复制、移动、删除、上传网盘 |
| 新建 | 新建空文件或文件夹 |
| 管理 | 重命名、复制、移动、删除（进回收站）、恢复或彻底删除 |
| 互传 | 选中后「上传网盘」，逐个传到当前 OpenList 目录，带进度可取消 |
| 预览 | 点文件交给系统查看器，通过 `content://` 安全共享，不暴露原始路径 |

安全策略：

- Android 11+ 未授予「所有文件访问权限」时自动退到应用私有外部目录，功能照常可用，顶部提供授权入口。
- 删除先进 `.PanXiaTrash` 回收站，可恢复到原位置；目标已存在时自动改名，不覆盖。
- 复制 / 移动遇到同名默认自动改名（如 `报告 (2).pdf`），**绝不静默覆盖**；同盘移动优先用系统重命名，跨盘才走流式复制。
- 大文件用 64 KB 缓冲流式复制并写临时文件，取消或失败会清理半成品，不留下打不开的残缺文件。
- 路径穿越、非法名称、空目录、路径不存在、权限不足、深层目录、目录移到自己内部等都有保护；批量操作逐项报告结果，单件失败不会中断整批。
- 核心操作层 `LocalFs` 是纯 Java，不依赖 Android，附带 67 项可在 JDK 上直接运行的自检用例。

## 安装

1. 从 [Releases](../../releases) 下载 `PanXia-1.2.apk`（或自行构建，见下）。
2. 允许「安装未知来源应用」后安装。
3. 打开 App，填写：
   - 服务器地址：`http://192.168.1.10:5244` 或 `https://pan.example.com`（不写 `http://` 会自动补上）
   - 用户名 / 密码：OpenList 后台账号
4. 点「登录」；也可以先点「测试连接」确认地址通不通。

> 提供的 APK 使用 debug 签名，未配置正式签名证书，安装时可能提示未知来源。

## 构建

要求：JDK 17、Android SDK（compileSdk 35）。不需要 Android Studio，也不需要任何第三方库。

```bash
# 1) 配置 SDK 路径（local.properties 不进版本库）
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

# 2) 构建
./gradlew assembleDebug        # Linux / macOS
gradlew.bat assembleDebug      # Windows

# 产物
app/build/outputs/apk/debug/app-debug.apk
```

如果 `gradlew` 没有执行权限（从 Windows 提交的文件常常会丢），先 `chmod +x gradlew`，或直接用 `sh gradlew assembleDebug`。

版本号规则：`versionName` 是 `主.次`，`versionCode = 主 × 10000 + 次 × 100 + 修订`（1.0 → 10000，1.1 → 10100，1.2 → 10200）。

## 接口对照

| 用途 | 接口 |
| --- | --- |
| 登录 | `POST /api/auth/login` → `data.token`，后续请求头 `Authorization: <token>`（不带 `Bearer`） |
| 探测 | `GET /api/public/settings` |
| 当前用户 | `GET /api/me` |
| 列目录 | `POST /api/fs/list`（`per_page=0` 一次列全） |
| 文件详情 / 直链 | `POST /api/fs/get` → `data.raw_url` |
| 上传 / 覆盖写入 | `PUT /api/fs/put`，路径放在 `File-Path` 头（URL 编码） |
| 新建 / 删除 / 重命名 | `POST /api/fs/mkdir` / `/api/fs/remove` / `/api/fs/rename` |
| 复制 / 移动 | `POST /api/fs/copy` / `/api/fs/move` |
| 目录树 | `POST /api/fs/dirs` |

预览与播放直接用 `raw_url`（带签名的直链），不需要额外认证头。
路径编码等价 `encodeURIComponent`（空格是 `%20` 而不是 `+`），中文与空格文件名已做往返验证。

## 已知限制

- **没有服务端搜索**：部分版本（如 v4.2.7）的 `/api/fs/search` 返回 404，所以筛选只在「当前目录」内做。
- **上传同名文件会覆盖**：会先弹确认，确认后是覆盖写入，没有「保留两者」。
- **复制/移动不合并冲突**：目标已存在同名文件时服务端会报错，需要先重命名。
- 不支持 OpenList 的分享链接管理、回收站、WebDAV、离线下载任务。
- 直链带签名，有效期由服务端决定；预览提示 403 时刷新目录重新取直链即可。
- 本地文件页在 Android 11+ 未授予「所有文件访问权限」时只能管理应用私有目录；即便授权，系统限制的部分目录（如 `Android/data`）仍可能无法访问。
- 回收站是应用内的 `.PanXiaTrash` 目录，卸载应用或手动清理该目录后不可恢复；它不是系统回收站。
- 跨存储的移动是「复制成功后删源」，不是原子操作；中途取消会保留已完成的项并给出逐项结果。
- GIF 只显示第一帧（系统 `BitmapFactory` 行为），要看动图可用「用浏览器打开」。
- PDF / Office 依赖手机里已安装的查看器。
- 超过 2 MB 的文本只读，避免把截断内容写回原文件。
- 按手机竖屏设计，未做平板 / 横屏大屏适配；音乐页锁定竖屏。
- 线上歌词库只取「有同步时间轴」的版本，纯文本歌词会按 4 秒一行铺开，可能与实际节奏对不上。
- 没有做后台播放服务（无通知栏控制、无蓝牙耳机按键接管），退出应用播放即停止。
- 视频播放依赖系统 `MediaPlayer`，个别封装（如部分 HEVC、AV1、内嵌 ASS 字幕的 MKV）可能放不了，此时可下载后用第三方播放器。
- 不支持字幕文件选择、硬件解码切换、画中画。

## 隐私与安全

- 账号密码只存在手机本地 `SharedPreferences`（异或 + Base64 **混淆**，不是加密），不会上传到任何第三方服务器。
- 登录 token 同样只存本地；「退出登录」只清当前服务器的 token 与密码，服务器条目保留。
- 没有统计上报，没有第三方 SDK，没有广告。本地文件页会申请「所有文件访问权限」，**仅用于浏览和管理手机上的文件**，拒绝后只会退到应用私有目录，不会上传任何本地文件；向网盘上传始终需要你手动选中并确认。
- 「忽略证书错误」只对开启该选项的那台服务器生效；打开后该连接不再校验证书，公网环境请谨慎。
